Installing

  1. Click Download at the top of any page. It downloads Thicket-Setup.exe, always the newest version.
  2. Run it, and follow the steps.

Release notes and older versions are on GitHub's releases page.

Thicket installs for your Windows account only, so it doesn't need an administrator password. It's added to the Start menu; a desktop icon is optional. It needs 64-bit Windows 10 or 11 (it's tested on Windows 11).

"Windows protected your PC" and other warnings

Thicket isn't signed with a paid certificate (one costs over £100 a year), so the first time you download and run it you may see two warnings. Both are normal for a new program:

  • Your browser may say the file "isn't commonly downloaded". Choose Keep. In Edge: click … next to the download, then Keep, then Show more › Keep anyway.
  • Windows may show a blue box, "Windows protected your PC". Click More info, then Run anyway.

Want to check your download is the real one? Every release gives the installer's checksum: a long code that changes if even one byte of the file does. It's in the release notes and in SHA256SUMS.txt. Run this in PowerShell and compare the code it shows:

Get-FileHash "$HOME\Downloads\Thicket-Setup*.exe"

The first start

Thicket asks where you record:

  • United Kingdom: the UK species list is built in, so there's nothing to download.
  • A US state: that state's species pack downloads in a few seconds and is checked before it's installed.

Then add your first sighting with the Add sighting button, or press Ctrl+N.

Upgrading

Download the newer installer and run it. It replaces the program and keeps everything else: sightings, photos, settings and backups. If Thicket is open, the installer asks you to close it first.

Thicket used to be called WildLife. Installing Thicket over WildLife upgrades it the same way.

Where your data lives

In the folder %LOCALAPPDATA%\WildLife on your PC. (It keeps the app's first name, so nothing went missing in the rename.) To open it, press Win+R, paste that name and press Enter. Thicket also shows the full path in Settings › Data.

Installing, upgrading and uninstalling never touch this folder.

Backups

Thicket backs up by itself once a day and when you close it, and checks each backup can be read back. It keeps the last 7 days, 4 weeks and 12 months.

Do one thing: choose a backup folder on another drive, such as a USB drive or a second disk. Until you do, backups sit next to your data, so they wouldn't survive that drive failing. Go to Settings › Backup › Backup folder. Back up now is there too.

Restoring a backup

Go to Settings › Backup › Restore… and pick a backup. Your data goes back to how it was then. Your current data is kept as a safety copy first, and Thicket restarts to finish.

If Thicket ever can't open your data when it starts, it offers to restore the latest backup.

Deleted something by mistake? Deleted sightings and photos wait in the recycle bin for 30 days (Settings › Data), and most changes can be undone straight away.

Moving to a new PC

  1. On your old PC, set your backup folder to a drive you can move, such as a USB drive (Settings › Backup › Backup folder), and click Back up now.
  2. On the new PC, install Thicket and plug in that drive. Or copy its whole backup folder across: it's called Thicket Backups (or WildLife Backups, if you set it up before the rename).
  3. Go to Settings › Backup › Restore… › Choose a backup file…, open the snapshots folder inside the backup folder, and pick the newest backup.

Thicket restarts with your sightings, places, outings and photos. Use the whole backup folder, not just one file: the photos are kept beside the backups.

Importing from iNaturalist

  1. On the iNaturalist website, use Export observations to download your observations as a CSV file.
  2. In Thicket, go to Settings › Import & export › From iNaturalist and choose the file.
  3. Check what Thicket found, then import. Also download the photos is ticked whenever online features are allowed, so the photos come too. Untick it if you'd rather not.

Importing a newer export later only adds what's new or changed. Spreadsheets import the same way, from From a spreadsheet.

Changing region

Go to Settings › Region. You can switch between the UK and US states, or add another state's pack for a trip. Packs only add species: your sightings never change.

Uninstalling

Open Windows Settings › Apps › Installed apps (Apps & features on Windows 10), find Thicket and choose Uninstall. Your data is kept, and the uninstaller tells you where. To remove it as well, delete the %LOCALAPPDATA%\WildLife folder afterwards (and your backup folder, if you chose one).

Is there a Mac or phone version?

No: Thicket is for Windows only. Out and about, take photos with your phone. Back home, add them to Thicket's Photo Inbox, and it reads when and where each one was taken. If you record with the iNaturalist app, you can import those records too.

Something's wrong

  • Settings › Data › Health check checks your data file, every photo, your backups and the species list, and explains anything it finds.
  • Still stuck? Report it on GitHub (you'll need a free GitHub account). Say what you did and what happened. Settings › About › Open log folder has Thicket's log files, which help. Have a look at them before attaching one: they can include folder and place names.
